# Барбер и Барби

Одностраничный сайт салона в Салавате на Next.js, TypeScript и App Router.

## Локальный запуск

```bash
npm install
npm run dev
```

## Переменные Vercel

В настройках проекта Vercel добавьте только серверные переменные:

- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота.
- `TELEGRAM_CHAT_ID` — chat ID, куда должны приходить заявки.
- `RESEND_API_KEY` — серверный API-ключ Resend с разрешением отправки писем.
- `BOOKING_EMAIL_FROM` — отправитель с подтверждённого в Resend домена, например `Барбер и Барби <booking@ваш-домен.ru>`.
- `NEXT_PUBLIC_SITE_URL` — итоговый HTTPS-домен сайта без завершающего `/`. Это публичный адрес для canonical, sitemap и schema, не секрет.

Секреты не добавляются в репозиторий и не попадают в браузер. Для локальной проверки создайте `.env.local` и удалите его из публикации.

Почтовые уведомления адресованы `Kav28leta1984@gmail.com`. Для включения почты подтвердите домен отправителя в Resend и задайте обе почтовые переменные на сервере (локально — в `.env.local`), затем перезапустите приложение. Адрес Gmail здесь является получателем, а не отправителем. API: https://resend.com/docs/api-reference/emails/send-email.

Telegram и email отправляются независимо. Если хотя бы один сервис принял заявку, форма сообщает об успехе, чтобы клиент не отправлял дубликаты; сбой второго канала записывается в серверный журнал без персональных данных. Без почтовых переменных Telegram продолжает работать. Если не доступен ни один канал, форма сообщает об ошибке. Приём запроса Resend не гарантирует попадания письма во входящие: реальную доставку проверьте после настройки ключа и отправителя.

## Что нужно заполнить до публикации

1. В `app/privacy/page.tsx` и `app/consent/page.tsx`: ФИО самозанятого, ИНН, адрес, контакты оператора и дату актуализации.
2. В `app/privacy/page.tsx`: подтвердить сроки хранения и схему передачи данных с юристом.
3. В `app/layout.tsx`: заменить `metadataBase` на фактический домен Vercel/сайта.
4. При необходимости заменить `public/favicon.svg` и добавить утверждённый логотип в `public/images`.

Политика и согласие — рабочие шаблоны, а не заявление о полном юридическом соответствии. Их нужно проверить с юристом после внесения реквизитов оператора.

## SEO перед запуском

1. Укажите в Vercel `NEXT_PUBLIC_SITE_URL` с итоговым HTTPS-доменом без завершающего `/`.
2. Перед существенными обновлениями сверяйте телефон, адрес и график с актуальной карточкой салона.
3. После подключения домена добавьте его в Яндекс.Вебмастер и Google Search Console, затем отправьте `/sitemap.xml`.
4. Просите отзывы только у реальных посетителей: не покупайте, не фильтруйте и не создавайте отзывы.
5. До включения формы на публичном домене перепроверьте реквизиты оператора в юридических документах.
